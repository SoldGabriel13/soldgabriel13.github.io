                Syntax and help

                Each box on the left is one part of the system. Edit any of them and the run restarts. Lines starting with # or // are comments, and ; can separate several items on one line.

                1. Equations 
                x' = v
v' = -k*x - c*v
E = 0.5*v^2 + 0.5*k*x^2

                A line with a prime on the left is a differential equation. x'' is the second derivative, and the lower ones (x') become variables you can plot and set. dx/dt = v and d2x/dt2 = ... mean the same. Any other line with a plain name on the left is a helper: a quantity computed from the state (energy, a distance) that can be plotted, drawn and used in other equations.

                stop: y < 0 ends the run when the condition becomes true. Write products with * and powers with ^. Comparisons give 1 or 0, and and / or combine them.

                Another variable instead of t. dy/dx = -2*x*y steps along x. Differential form: dN/N = k*dt or dN = k*N*dt work as long as they are linear in the differentials and every unknown gets one equation.

                2. Parameters and initial values 
                g = 9.81
L = 1
m = 2*L        # may use earlier parameters

                Every parameter gets a slider that changes the run while it plays. Initial values are written x = 1 or x(0) = 1, and for derivatives x' = 0 or x'(0) = 0. Anything left out starts at 0. A parameter can also be an initial value of a variable (such as x0) and the run restarts when you move it.

                3. Functions, fields and calculus 
                f(a, b) = a^2 + sin(b)
F(x, y) = (-y, x)        # a vector field
Phi(z) = exp(-z^2)

                A function can use its arguments, parameters, state variables and the independent variable. If it returns a pair it is a vector field, drawn as arrows in the scene; read its parts as F_x(px, py) and F_y(px, py). A function of two numbers can also be shaded (blue positive, orange negative) with the chips above the scene.

                D(expr, v) is a partial derivative of any expression, and integral(expr, u, from, to) a numeric integral (nestable). For example -D(Phi(z), z)*z' is the EMF induced in a loop by a moving magnet.

                Built in: sin cos tan asin acos atan atan2 sinh cosh tanh exp log sqrt cbrt abs sign floor ceil min max pow hypot mod step ifelse(cond, a, b). Constants: pi, e, tau.

                4. Vectors 
                r'' = grav - drag*r'
grav = (0, -9.8)
r = (-4, 4)
r' = (2.5, 0)
E = 0.5*dot(r', r')

                Any variable, parameter or helper can be a vector: write it as (a, b) or (a, b, c). The vector is split into components named r_x, r_y, r_z behind the scenes, so those names appear in plots and sliders. Use r.x or r'.y for one component. Vectors add, subtract and scale (2*v, v/3). To multiply two vectors use dot(a, b) or cross(a, b).

                Also: norm(v) (length), unit(v), perp(v) (2D, turned 90°), rot(v, angle), proj(a, b), angle(a, b). A scalar function such as sin needs single numbers, so use a component.

                5. Drawing the scene 
                bob: L*sin(th), -L*cos(th)       # a point
ball: r                          # a vector is a point
rod: x, 0, x, 1                  # a segment
arrow v: r, r'*0.4               # arrow from r, length v
view: -5, 5, -1, 6               # fixed window

                Two numbers make a point, four make a segment, and an arrow line takes a start and a vector. The box below the drawing list can join the points with rods from the origin (for pendulums). Text before the colon is the label.

                The scene camera has three modes: Follow keeps the points in view, Locked keeps the view where it is (presets with a view: line start locked), and Free lets you drag to pan, scroll or pinch to zoom, double-click to refit. Refit view fits everything again.

                6. Actions and buttons 
                when y < 0 and y' < 0: set y' to -0.8*y'; set y to 0
when T > 22 once: set heater to 0
at 5: set k to 2
every 2: set x' to 3
action Kick: set x' to 3
set x to 0                       # a bare set is a button

                when fires when its condition turns true, not while it stays true, and a crossing is caught at the first step after it, so timing is off by up to one step. once limits it to one firing. at T fires at a time and every P repeats. action Name: makes a button you can press at any moment.

                set changes a stored variable or a parameter (parameter changes undo on Reset and move the sliders). Only stored values can be set: use x' in a second-order equation, not in a first-order one. Several sets run together and all use the values from before the action, so set x to y; set y to x swaps them. stop also works as an action. The last few firings are listed under the controls.

                7. Fields on a grid (PDEs, Maxwell) 
                grid 72 x 72 on -6..6, -6..6
boundary absorb 10 6
vector E, B
J = (0, 0, I0*sin(w*t)*exp(-(x^2+y^2)/s2))
B' = -curl(E)
E' = c^2*curl(B) - J
U = 0.5*(dot(E, E) + c^2*dot(B, B))

                The grid line sets the number of points and the region. scalar u declares scalar fields and vector E, B vector ones (3 components; vector E[2] for 2). Equations with a prime are applied at every grid point and can use x, y (also gx, gy if a variable already has that name), t, parameters and your ordinary variables. u'' = c^2*lap(u) is a wave equation. init E = (0, 0, exp(-(x^2+y^2))) sets the starting field. A plain name = ... is a helper field recomputed each step (sources, energy density, E = -grad(phi)).

                Operators: grad(u), div(F), curl(F), lap(u), and the partial derivatives Dx Dy Dxx Dyy. They need a field name inside; to differentiate an expression, make it a helper first. Fields depend on x and y only, so the z component of a vector is just a component that does not vary with z.

                Time stepping: equations run in the order written and each sees the latest values, so write B' before E'. Keep dt below the grid spacing divided by the wave speed or the grid blows up (you get a message). Boundaries: reflect (default), wall (fields forced to zero at the edge, loses some energy), periodic, absorb [width in cells] [strength].

                Fields and particles: sample(E, px, py) reads a field at any point (a vector field gives a vector), fsum(U) integrates a field over the grid and fmax(U) is its largest size. Both work in ordinary equations and helpers, for example W = fsum(U) to plot the total energy, or v' = q*(sample(E, r.x, r.y) + cross(v, sample(B, r.x, r.y))) for the Lorentz force. Particles feel the fields but do not push back on them. Choose what to show with the Show list above the scene (a vector offers its magnitude and each component), tick Arrows for direction, and set Range to fix the colour scale. Hover to read a value.

                8. Plots, derivatives and layout

                Time series: click a chip to show or hide a curve. Window is how many time units stay on screen (0 shows everything), Trail how long the points leave a tail, Speed the playback rate, and Step dt the integration step. Phase: pick any two quantities for the axes.

                Derivatives: pick any numerator and denominator, from time, variables and helpers, and the card plots dA/dB (against time or against the denominator) with no formula needed. It is computed as (dA/dt)/(dB/dt) along the run. "All pairs" shows every ratio now; click a cell to plot it.

                Typeset: shows your equations in LaTeX. Choose dots or d/dt notation, and the LaTeX button gives source you can copy. Every panel can be hidden, made fullscreen (Esc exits) or resized with its corner grip (double-click the grip to reset). Save / load writes the whole system, the view and your settings as text you can copy and paste back later.
